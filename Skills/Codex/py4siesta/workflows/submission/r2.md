## Procedure, inputs, outputs, and validation

Menus: `9` (k-points), `10` (optimization). Read [mcp.md](../../references/mcp.md) before execution.

Use only when submission is included in the user's request. Inspect origin, scripts,
resources, and actual target list first. `py4siesta_tool_submit {"parameters": {"mode": "kpt"}, "workdir": "/absolute/calculation/directory"}` chooses the FIRST sorted
`01.*` directory; `py4siesta_tool_submit {"parameters": {"mode": "opt"}, "workdir": "/absolute/calculation/directory"}` chooses the FIRST sorted `02.*` directory. It
then calls sbatch for EVERY `slm_*` in every immediate child directory. It does not
filter completed jobs, choose a requested scan, or deduplicate submissions. An
`optimized_structure` child containing a copied script can therefore also be submitted.

If that exact target set does not match the request, do not run the batch command.
Explain the mismatch; only use another verified MCP submission tool after an
announced, authorized free-mode transition. If none fits, stop submission.
No matching directory can return successfully without submitting anything.

```text
py4siesta_tool_submit {"parameters": {"mode": "kpt"}, "workdir": "/absolute/calculation/directory"}
# Or, after verifying the optimization target set:
py4siesta_tool_submit {"parameters": {"mode": "opt"}, "workdir": "/absolute/calculation/directory"}
```

Capture each sbatch response, job ID, script, and case path immediately in history.
On partial failure, reconcile successful IDs and scheduler status before any retry;
never rerun the full command blindly. If IDs were lost, inspect scheduler/accounting
records and script logs. Unknown submission state must not trigger automatic resubmission.

Submission success means submitted, not calculated. Use a verified, enabled scheduler-query MCP tool when requested. If none is
available, retain IDs and mark waiting; obtain external status evidence from the user. Track pending/running/failed/completed
states and inspect SIESTA convergence separately. Save the next step and IDs when the
session stops. Resume from these records without regenerating cases or repeating jobs.

The MCP log may be truncated at 64 KiB. If complete script-to-ID mapping cannot
be recovered, preserve submission intent and uncertain status; never resubmit to
recover missing IDs. This recipe covers kpt/opt only, not the geometry mode.
